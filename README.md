# Café Colômbia Itu

Site institucional responsivo desenvolvido em HTML5, CSS3, Bootstrap 5.3 e JavaScript puro.

## Estrutura

- `index.html`: página principal
- `assets/css/style.css`: identidade visual e responsividade
- `assets/js/main.js`: animações, filtros e navegação
- `assets/images/`: imagens do projeto

## Como abrir

Abra `index.html` em um navegador. O Bootstrap, os ícones e as fontes são carregados por CDN, portanto é necessário acesso à internet.

## Antes de publicar

- Confirmar o endereço: fontes públicas divergem entre Rua Santa Rita, 1752 e 1779.
- Confirmar o horário completo de sábado.
- Confirmar se o telefone `(11) 2429-3917` também recebe WhatsApp. O site usa ligação telefônica para não prometer um canal não verificado.
- Substituir os itens ilustrativos do cardápio por cardápio e preços oficiais.
- Obter aprovação para uso das imagens e textos finais.
